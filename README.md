# Big Pencils — аддон для Minecraft PE / Bedrock

Гигантские карандаши (≈3,75 блока высотой) с глазами и улыбкой случайно спавнятся по всему миру Верхнего мира.
Каждый получает **случайный цвет из 16** (как у красителей). Они бродят, покачиваются при ходьбе, смотрят на игрока,
а при убийстве роняют палки и древесный уголь («грифель»).

## Установка
1. Скачайте `dist/BigPencils.mcaddon` на телефон и откройте его — Minecraft сам импортирует оба пака.
2. В настройках мира включите **Behavior Pack** и **Resource Pack** «Big Pencils».
3. Играйте — карандаши появятся сами. Или призовите: яйцо спавна «Большой карандаш» либо `/summon pencil:big_pencil`.

Нужна версия Minecraft Bedrock 1.20+. Экспериментальные функции не требуются.

## Структура
- `BigPencils_BP` — поведение: сущность, правила спавна, лут
- `BigPencils_RP` — ресурсы: модель, 16 текстур, анимация, переводы (EN/RU)
- `tools/generate.py` — генерирует текстуры и повторяющиеся JSON (`python3 tools/generate.py`)
- `tools/build.py` — собирает `dist/BigPencils.mcaddon`

## Настройка
Частота спавна — `weight` в `BigPencils_BP/spawn_rules/big_pencil.json`; размер — `collision_box` и модель.
