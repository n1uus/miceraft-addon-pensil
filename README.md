# Big Pencils — аддон для Minecraft PE / Bedrock

Гигантские карандаши (≈3,75 блока высотой) с глазами и улыбкой случайно спавнятся по всему миру Верхнего мира.
Каждый получает **случайный цвет из 16** (как у красителей). Они бродят, покачиваются при ходьбе, смотрят на игрока,
а при убийстве роняют палки и древесный уголь («грифель»).

## Установка
1. Скачайте `dist/BigPencils.mcaddon` на телефон и откройте его — Minecraft сам импортирует оба пака.
2. В настройках мира включите **Behavior Pack** и **Resource Pack** «Big Pencils».
3. Играйте — карандаши появятся сами. Или призовите: яйцо спавна «Большой карандаш» либо `/summon pencil:big_pencil`.

Нужна версия Minecraft Bedrock 1.20+. Экспериментальные функции не требуются.

## Структура
- `BigPencils_BP` — поведение: сущность, правила спавна, лут
- `BigPencils_RP` — ресурсы: модель, 16 текстур, анимация, переводы (EN/RU)
- `tools/generate.py` — генерирует текстуры и повторяющиеся JSON (`python3 tools/generate.py`)
- `tools/build.py` — собирает `dist/BigPencils.mcaddon`

## Настройка
Частота спавна — `weight` в `BigPencils_BP/spawn_rules/big_pencil.json`; размер — `collision_box` и модель.

# Random Hammers — случайные молотки-«Т»

Молотки в форме буквы **Т**: сверху голова шириной 3 блока, по центру вниз — палка-ручка. Часто спавнятся в Верхнем мире,
у каждого **свой случайный цвет** головы и ручки (32 раскраски), у них есть глаза. Их **можно убить** (20 HP) — выпадают железо и палки.

Установка: `dist/RandomHammers.mcaddon` → включить Behavior + Resource Pack «Random Hammers». Яйцо спавна или `/summon hammer:random_hammer`.

## Настройки (оси X и Y)
Файл `hammers_config.json`:
- `size_x` — размер по оси X (ширина/глубина), `size_y` — размер по оси Y (высота); 1.0 = 3×3 блока
- `spawn_weight`, `herd_min`, `herd_max` — частота спавна и размер групп
- `rotation_x`, `rotation_y` — угол наклона/поворота в градусах по осям X и Y
- `spin_x`, `spin_y` — скорость постоянного вращения (градусов в секунду) по осям X и Y, 0 = не крутится
- `health` — здоровье; `color_variants`, `color_seed` — количество и «зерно» случайных цветов

После правки: `python3 tools/hammers.py` — пересоберёт `dist/RandomHammers.mcaddon` (нужен Pillow).

По умолчанию молоток перевёрнут (`rotation_x`: 180) и крутится вокруг своей оси (`spin_y`: 90°/сек). Чтобы поставить прямо и без вращения — `rotation_x`: 0, `spin_y`: 0.
На молоток можно **сесть** (ПКМ / нажатие на него) — сиденье наверху на высоте `3 × size_y`.
